Website Panel

Apne pages aur blog posts khud banayein — bina code ke

Step 1 — GitHub Key

Publish karne ke liye ek dafa ki GitHub key chahiye. Key sirf isi browser mein rehti hai — website par ya kisi aur ko nahi jati.
Key banane ke liye: GitHub par new key banayein → Repository access mein sirf digital-dokan chunein → Permissions mein Contents: Read and write dein → Generate → copy karke yahan laga dein.

Step 2 — Page Banayein

Neeche Template Gallery se apni pasand ka design chunein — har template ki preview dikhti hai aur content pehle se bhara hota hai, aap bas apna text aur tasveer badlein. Structure badalna ho to blocks ko upar/neeche karein, naya block jorein ya hata dein. Neeche Live Preview mein page sath sath banta hua dikhega — bilkul WordPress ki tarah.

Page ke Blocks (Structure)

Har block page ka ek hissa hai. Text wale khano mein: khali line = naya paragraph, **do sitare** = bold, [ye text](https://link) = link.

Live Preview — Page Banta Hua

Upar jo kuch likhein ya badlein, wo yahan sath sath dikhta hai. Ye sirf preview hai — asal page Publish dabane se live hoga.

Mere Banaye Hue Pages

Jo pages is panel se bane hain, wo yahan ayenge. Edit dabane se page editor mein khul jayega; dobara Publish karne se update ho jayega.
